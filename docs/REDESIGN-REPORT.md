# Vyro Web — Professional Redesign Report

**Scope:** layout/CSS/component-structure redesign of the dashboard and editor to a Word-grade UX with Vyro's own identity. The data/logic layer was NOT rewritten: `store.ts` semantics, localStorage keys/formats (`vyro-web-docs-v1`, theme, `vyro-web-ui-lang`), `entitlement.ts`, the three premium gates (DOCX export, Print/PDF, custom templates), the env-gated Supabase client, template contents and `docx.ts` import/export are all unchanged. No new runtime dependencies. No tests were modified.

**Verification (this machine, this run):**
- `npm test` → **33/33 pass** (6 files: entitlement 8, store 3, store regressions 9, dir 4, templates 4, i18n 5). No test needed changes — the i18n additions are additive and the identical-key-set test passes.
- `npm run build` → **passes** (tsc + Vite). dist produced; both Vazirmatn woff2 files are in `dist/fonts/` and referenced by the built CSS.
- Dialog hygiene: `grep -rn "prompt(\|confirm(\|alert(" src/` over all application code (`*.tsx` + non-test `*.ts`) → **zero calls**; `window.prompt/confirm/alert` → none. The only two remaining grep hits in the whole tree are inert string literals inside the pre-existing security regression test (`store.regression.test.ts` lines 59/66: an XSS payload string and a `javascript:` URL string used as test data) — they are data the security tests feed to `escapeHtml`/`isSafeLinkUrl`, not dialog calls, and removing them would weaken those tests.
- `npm run lint` → 0 errors (warnings only; the `Btn`/`Group` render-local component pattern is pre-existing and was preserved deliberately).

## A) Design system (`src/index.css`, full rewrite)
- CSS custom-property tokens shared by light + dark: brand palette (Vyro blue, deep/soft/ink variants), surfaces, text, borders, canvas, danger/warn, spacing scale (`--sp-1..6`), radii, four shadow levels (incl. a realistic two-layer page shadow), focus colour. Both themes consume the same tokens; the document page stays paper-white in both (like Word).
- Typography: `Inter, system-ui, …` for EN; **Vazirmatn self-hosted** — `Vazirmatn-Regular.woff2` (50,684 B) and `Vazirmatn-Bold.woff2` (51,020 B) downloaded from jsDelivr (rastikerdar/vazirmatn v33.003) into `public/fonts/`, wired via `@font-face` (`font-display: swap`), first in the FA UI stack and present in the document font stack so Dari glyphs render in Vazirmatn even inside LTR documents.
- Consistent primitives: gradient primary button, bordered secondary buttons, pill language toggle, icon buttons, chips/badges, cards, modal, toast — one radius/spacing language everywhere; `:focus-visible` rings via token; `@media (pointer:coarse)` raises targets to ≥44px (ribbon buttons 42px+ with padding).

## B) Dashboard (`src/App.tsx`, restructured)
- Sticky app bar: Vyro wordmark, **centred pill search** (with clear button), EN/فارسی pill toggle, theme toggle, and a compact subscription chip (Local/Free/Premium ★) that opens the Premium modal. On mobile the search drops to its own full-width row under the bar — nothing overflows.
- Create section: a prominent bordered **"+ New document" card** (sheet preview with a big +) followed by the templates as visual cards in a snap-scrolling row — each with a CSS sheet thumbnail (title bar + text lines), name and description, incl. the Dari نامه رسمی (RTL) and the custom-template card (premium lock behaviour unchanged).
- Sidebar (desktop): folder navigation list with per-folder document counts, an "All documents" entry, and a Favorites toggle with count; the subscription/auth card kept but compact. Mobile (<900px): the layout becomes single-column via grid areas — the nav turns into a horizontal chip row on top, documents in the middle, the subscription card at the bottom.
- Document cards: rich cards with 2-line-clamped `dir="auto"` title (mixed FA/EN titles render correctly), updated time, direction badge (LTR · English / RTL · دری/فارسی), folder badge, favorite star toggle, and a **kebab (⋯) overflow menu** (Rename / Folder / Duplicate / Delete) with a click-away backdrop.
- **`window.prompt`/`confirm` fully removed from the dashboard:** Rename and Folder open an **inline editor inside the card** (labelled input, Save/Cancel, Enter commits, Esc cancels, rename ignores empty); Delete becomes an **inline confirm state** in the card (document name shown, Delete/Cancel); custom-template naming is now a **small modal** (input + Create/Cancel, Create disabled while empty) reusing the modal styles. All mutations still go through the same pure `store.ts` functions with functional `setDocs` updates.

## C) Editor (`src/components/Editor.tsx`, restructured chrome)
- Title bar: back button + wordmark, centred editable title (`dir="auto"`), save state, plan badge, **EN/فا language quick toggle** and theme toggle (new `onLangChange` prop wired to the existing App language state — UI language and document direction stay independent, as before).
- Ribbon: same seven tabs and only-working controls, regrouped per Word's Home order — History | Style (block style, **font family (new)**, font size) | Font (B/I/U/S, text colour, highlight, clear formatting) | Paragraph (alignments) | Lists. Group captions on desktop; brand-gradient tab strip with the active tab seated on the ribbon surface.
- Mobile ribbon: the tab strip scrolls horizontally and gains a **"More tools" expand toggle**; in its resting state the ribbon is a single horizontally scrollable row of core controls with captions hidden (~2 rows total with the tabs), expanding to a wrapped, captioned panel (max 46vh) on demand. Save state moves into the status bar on small screens so the title bar never crowds.
- Page/canvas: neutral canvas token; the A4 sheet (210mm, 2.54cm default margins, landscape swap) is centred with the new page shadow. The old CSS `zoom` property is **gone**: the sheet now sits in a `transform: scale()` wrapper whose width/height are compensated from measured values (ResizeObserver on the workspace for fit-to-width, on the sheet for height). Effective scale = fit-to-width (≤1, so the sheet always fits narrow screens) × user zoom 50–200%; at 150%/200% the sheet grows inside the workspace's own scroll area — the app itself never scrolls horizontally. Print CSS resets the scaler (`position: static`, `transform: none !important`, auto size) and keeps the named `@page` portrait/landscape rules.
- Status bar: Word-style brand strip — save state (mobile), word/char count, direction indicator (LTR · English / RTL · دری/فارسی), and zoom −/slider/+ controls.
- Link dialog: the Insert tab's `prompt()` is replaced by an **inline link popover** (URL input, Save / Remove link / Cancel, Enter applies, Esc closes) — the existing `isSafeLinkUrl` gate (http/https/mailto only) is enforced exactly as before.
- Dari/Persian details: placeholder now uses the translated `startTyping` string and renders via the standard TipTap placeholder CSS (`float: inline-start`, correct side in RTL); lists use `padding-inline-start`, blockquotes `border-inline-start`, so RTL lists/quotes mirror correctly; per-document `dir` handling is untouched.
- All previous editor features preserved: autosave with flush-on-unmount/Back/Save-now, import TXT/DOCX, TXT/HTML export, gated DOCX/print, tables, validated image insert (MIME + 2MB), TOC from headings, spellcheck toggle, margins/orientation/direction, View-tab zoom + theme.

## D) i18n
New keys added to **both** dictionaries (EN/FA): `save`, `cancel`, `create`, `moreActions`, `deleteConfirm`, `folderNamePlaceholder`, `removeLink`, `moreTools`, `allDocuments`, `foldersHeading`, `newBlankDoc`, `fontFamily`. The old `renamePrompt`/`folderPrompt`/`deleteConfirmPrefix`/`customTemplatePrompt` keys remain in the dictionaries (some still used as labels) — key sets stay identical, which the i18n test pins.

## Could NOT do / honest limits

The mobile ribbon, fit-to-width scaler and zoom behaviour are implemented and build-verified, but the tap-through check at 150%/200% zoom, on a real phone viewport and in FA mode, still needs the parent's live pass on the deployed URL — it is NOT claimed here.
- The new **font-family select does not reflect the family at the current selection** (set-only dropdown), the same known limitation class as the pre-existing font-size dropdown; read-back wiring was left out to avoid touching the editor's mark handling.
- Bundle size is unchanged (~951 kB main chunk, gzip ~294 kB) — pre-existing; code-splitting remains a future task.
- Vazirmatn download **succeeded**, so no fallback was needed; only Regular (400–600) and Bold (700–900) weights are self-hosted.
